# DSA

This repository holds my **LeetCode solutions**, synced automatically every time I solve a problem on [LeetCode](https://leetcode.com).

Each solved problem gets its own folder, named after the problem, containing the solution file(s) and (when available) the problem's notes/description.

```
DSA/
├── 1-two-sum/
├── 2-add-two-numbers/
├── ...
└── README.md
```
## About

- 🔄 **Auto-synced** — solutions are pushed here directly from LeetCode as I solve problems, so this repo always reflects my up-to-date submission history.
- 📁 **One folder per problem** — folder names follow the pattern `<problem-number>-<problem-slug>` (e.g. `1-two-sum`).
- 🌐 **Multi-language** — solutions may be in different languages depending on what I used to solve the problem on LeetCode.
